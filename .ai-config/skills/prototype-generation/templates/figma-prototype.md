# Figma 设计稿模板

> 适用于判定分数 5+ 且偏向静态展示，或 ≥8 分场景与 HTML 混合。

## 输出位置

`docs/prototype/REQ-XXXXXXXX.figma`（Figma 链接或导出图）

## 包含内容

- 完整的 UI 设计（颜色、字体、间距）
- 组件库标注
- 交互流程标注
- 响应式设计说明
- 设计规范（颜色、字体、按钮样式等）

## 集成方案

**选项 1：导出 Figma 设计稿**
- 使用 Figma API 生成设计稿
- 导出为 PNG/SVG 保存到 docs/prototype/
- 在需求文档中嵌入图片链接

**选项 2：生成 Figma 链接**
- 创建共享链接
- 在需求文档中包含可点击的 Figma 链接
- 便于多人实时评审

**选项 3：使用 Figma 插件**
- 与 Figma 系统集成，更新时实时同步

## 何时选 Figma 而不是 HTML

- 不需要交互演示，只展示静态视觉
- 多人评审 / 批注场景
- 需要细致的视觉规范交付（色卡、字体、间距）
- 设计师后续会基于此扩展
