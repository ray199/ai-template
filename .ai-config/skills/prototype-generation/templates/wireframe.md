# 低保真草图模板

> 适用于判定分数 3-4 分。输出 markdown ASCII 线框图，工期 2-5 分钟。

## 输出位置

`docs/prototype/REQ-XXXXXXXX-wireframe.md`

## 模板示例

```markdown
### 原型概览 - 低保真度

【用户管理系统 - 主页面布局】

┌─────────────────────────────────────┐
│ 用户管理系统        [退出]          │  <- 顶部导航
├─────────────────────────────────────┤
│ ☰ 菜单                              │
├────────┬──────────────────────────┤
│        │ 【用户列表】              │
│        │                          │
│  菜单  │ [搜索] [高级筛选] [导出] │
│        │                          │
│  ├─ 用户│┌──────────────────────┐│
│  │ 管理 ││ 用户名 | 邮箱 | 操作  ││
│  │      ││────────────────────│
│  ├─ 角色│││ user1  | x@x.com│编辑│
│  │ 权限 │││ user2  | y@y.com│删除│
│  │      │└──────────────────────┘│
│  └─ 日志│                          │
│        │ 分页: [1][2][3] ... [10] │
└────────┴──────────────────────────┘

【流程说明】
1. 用户点击"高级筛选" → 展开筛选面板
2. 选择条件后点击"查询" → 刷新列表
3. 点击用户行 → 打开详情编辑对话框
```

## 优势

- 极低生成成本（2-5 分钟）
- 易迭代和修改
- markdown 友好，可入 git
- 适合快速概念验证、内部沟通
