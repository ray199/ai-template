# 原型输出格式与文件组织

## 文件组织

```
docs/prototype/
├─ REQ-20240315-001.html          (HTML 原型)
├─ REQ-20240315-001.figma         (Figma 链接或导出)
├─ REQ-20240315-001-wireframe.md  (低保真草图)
└─ README.md                       (原型说明)
```

## 需求文档中的引入格式

```markdown
## 原型

### 原型概览
- **形式**: HTML 可交互原型 + Figma 设计稿
- **查看方式**:
  - [点击打开 HTML 原型](../prototype/REQ-XXXXXXXX.html)
  - [Figma 设计稿链接](https://figma.com/...)
  - [低保真线框图](#低保真线框图)

### 关键交互流程
1. 用户在搜索框输入 → 实时搜索结果
2. 点击"编辑" → 打开编辑对话框
3. 编辑后点击"保存" → 列表更新

### 页面清单
| 页面名 | 说明 | 状态 |
|---|---|---|
| 用户列表 | 展示所有用户 | ✅ 原型完成 |
| 用户详情 | 编辑用户信息 | ✅ 原型完成 |
| 角色权限 | 配置角色权限 | ⚠️ 待确认 |

### 设计规范
- 色系: 蓝白配色（企业风格）
- 字体: 微软雅黑 / Roboto
- 组件库: Ant Design
- 响应式: 1024px 以上

### 验收标准 vs 原型对标
| 验收标准 | 原型体现 | 确认 |
|---|---|---|
| 支持模糊搜索 | HTML 搜索框实现 | ✓ |
| 支持批量导出 | 原型中展示导出按钮 | ✓ |
| 权限配置 UI 清晰 | Figma 设计稿展示 | ⚠️ 待细化 |
```

## 不同分数的输出示例

```
需求: 支持用户列表、搜索和导出
判分: 功能 1 + 复杂 1 + 涉众 0 + 验收 1 = 3 分
输出: docs/prototype/REQ-XXX-wireframe.md（ASCII 线框图）
```

```
需求: 订单管理，涉及多步骤流程
判分: 功能 3 + 复杂 2 + 涉众 1 + 验收 1 = 7 分
输出: docs/prototype/REQ-XXX.html

```

判分: 功能 3 + 复杂 3 + 涉众 2 + 验收 2 = 10 分
输出:
  docs/prototype/REQ-XXX.html      （完整可交互大屏 + 响应式）
