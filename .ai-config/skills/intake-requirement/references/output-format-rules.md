# 输出文档格式规范（Word / 飞书转换兼容）

所有生成的需求文档必须符合 `.ai-config/rules/doc-format-standard.md` 的格式规范。

## AI 生成需求文档时的必须行为

生成 `docs/requirements/backlog/REQ-XXXXXXXX.md` 时：

1. **替换所有 HTML 注释**：模板中的 `<!-- ... -->` 占位符必须全部替换为实际内容，不可保留
2. **无法推断的字段**：使用 `（待填写）` 代替空白或注释
3. **删除填写说明**：模板中的"填写说明："等纯指引性文字必须删除
4. **禁止代码块包裹非代码**：说明文字、规则描述改用普通段落或表格
5. **最多使用 H3 标题**：禁止使用 H4 及以下标题层级
6. **禁止 HTML 标签**：不使用 `<br>`、`<div>` 等任何 HTML 元素

## 格式自检（Step 4 新增检查项）

| 检查项 | 合规条件 |
|---|---|
| 无 HTML 注释残留 | 文档中不含 `<!--` 字符串 |
| 标题层级合规 | 无 `####` 及以下标题 |
| 代码块合规 | 代码块内容均为代码/命令/配置，非说明文字 |
| 无 HTML 标签 | 文档中不含 `<br>` / `<div>` 等标签 |
| 占位符可见 | 未确定字段使用 `（待填写）` 而非空白 |
