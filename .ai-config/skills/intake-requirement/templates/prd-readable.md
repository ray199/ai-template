## 三、能做什么（核心功能描述）

> 用"用户故事"表述，避免技术术语。

**故事 1：管理员创建权限组**
- 作为管理员，我希望可以创建带名称和描述的权限组，
  这样我能把一组相关权限打包给团队使用。

**故事 2：管理员给用户分配权限组**
- 作为管理员，我希望从用户列表中选中用户后批量分配权限组，
  这样能避免逐个用户配置的重复劳动。

**故事 3：用户查看自己的权限**
- 作为普通用户，我希望在个人中心看到自己拥有的权限组列表，
  这样我能清楚知道自己能做什么。

## 四、用户怎么操作（主流程）

> 文字描述完整操作路径，搭配原型链接。

**流程 A · 创建并分配权限组**

1. 管理员登录后台 → 进入「权限管理」
2. 点击「创建权限组」→ 填写名称 / 描述 / 选择权限项 → 保存
3. 切换到「用户列表」标签页
4. 勾选若干用户 → 点击「批量分配权限组」→ 选择刚创建的权限组 → 确认
5. 系统提示分配成功，被分配用户立即生效

> 涉及前端的 → 附 [UI 原型链接](../prototype/REQ-xxx.html) 或 [Figma 链接]
