# 技能：需求接入与工作量评估

将任意形式的原始需求转化为标准结构化需求文档，执行工作量联合评估（需求分析师 + 架构师），根据评估结果确定输出物规范。

用户输入的需求内容：$ARGUMENTS

## 完整处理流程（5步）

```
原始需求输入（一句话 / 零散 / 半结构化 / 完整PRD）
   ↓
【Step 0A】项目上下文感知（自动执行）
   - 扫描项目目录，识别技术栈、已有模块、历史需求
   - 输出：项目上下文摘要 + 可利用资源清单
   ↓
【Step 0B】输入质量识别（自动执行）
   - T1（一句话）→ 引导式问答（3问）
   - T2（零散）  → 主动推断 + 精准澄清（最多3问）
   - T3（半结构化）→ 自动补全 + 少量确认（最多2问）
   - T4（完整PRD）→ 直接结构化（0问）
   ↓
【Step 1】需求结构化
   - 利用 Step 0A 上下文自动填写已知字段，标注来源（✅自动/⚠️推断/❓缺失）
   - 完整性检查：6个核心字段必须全部非空
   - 通过后分配 need_id → 保存至 docs/requirements/backlog/REQ-YYYYMMDD-XXX.md
   ↓
【Step 2】工作量联合评估
   - 需求分析师：业务维度5项评分（页面数/接口数/DB变更/影响范围/数据迁移）
   - 架构师代理：技术维度4项评分（架构变更/新技术/性能并发/安全权限）
   - 综合判定等级：S / M / L / XL
   ↓
【Step 3/4】输出物规范确认 + 质量检查
   - S：AI全自动检查 → 直接进入编码
   - M：AI初检 + 人工确认
   - L/XL：AI初检 + 人工终审
```

## 核心必填字段（Step 1 完整性检查）

| 字段 | 检查规则 |
|---|---|
| `need_id` | 自动分配，格式 REQ-YYYYMMDD-XXX |
| `title` | 不超过20字，包含动词+对象 |
| `priority` | P0 / P1 / P2，需说明定级理由 |
| `deadline` | 具体日期或明确里程碑（不接受"尽快"） |
| `goal` | 必须可量化（含数字或可验证的状态） |
| `acceptance` | 至少1条，格式："当[条件]时，系统应[行为]" |

## 工作量等级判定

### 业务维度（需求分析师，5项）
| 维度 | 低(1分) | 中(2分) | 高(3分) |
|---|---|---|---|
| 涉及页面数 | 0-1 | 2-4 | 5+ |
| 涉及接口数 | 0-2 | 3-6 | 7+ |
| 数据库变更 | 无 | 改字段/索引 | 新表/重构 |
| 影响已有功能 | 无 | 局部 | 跨模块/核心 |
| 数据迁移 | 无 | 可自动化 | 需人工 |

### 技术维度（架构师，4项）
| 维度 | 低(1分) | 中(2分) | 高(3分) |
|---|---|---|---|
| 架构变更范围 | 无 | 单模块 | 跨模块/新组件 |
| 引入新技术 | 否 | 轻量 | 重型/第三方 |
| 性能/并发挑战 | 无要求 | 百级QPS | 高并发/大数据 |
| 安全/权限变更 | 无 | 局部 | 核心逻辑 |

### 等级判定规则
| 条件 | 等级 | 工期 |
|---|---|---|
| 业务分≤7 且 技术分≤6，无3分项 | **S** | 1-2天 |
| 业务分8-10 或 技术分7-8，最多1个3分项 | **M** | 3-5天 |
| 业务分11-13 或 技术分9-10，有1-2个3分项 | **L** | 1-2周 |
| 业务分≥14 或 技术分≥11，多个3分项 | **XL** | 需拆分 |

兜底规则：单个3分项且涉及核心业务 → 升L；多个3分项或跨迭代 → 升XL

## 输出格式（Step 1 通过后）

```markdown
# 需求文档：[需求标题]

- **need_id**: REQ-YYYYMMDD-XXX
- **优先级**: P0/P1/P2
- **期望上线**: YYYY-MM-DD

## 背景与目标
[内容]

## 功能范围
- 包含：[列表]
- 不包含：[列表]

## 验收标准
1. 当[条件]时，系统应[行为]

---
✅ 完整性检查通过，准备进入 Step 2 工作量评估。
```

## 文档格式规范（生成文档时必须遵守）

1. 替换所有 HTML 注释 `<!-- -->` 为实际内容
2. 无法推断的字段使用 `（待填写）`，不留空白
3. 禁止使用 H4 及以下标题层级
4. 禁止代码块包裹非代码内容（说明文字改用段落或表格）
5. 禁止使用 `<br>`、`<div>` 等 HTML 标签

完成后告知用户下一步：`/ai:evaluate REQ-XXXXXXXX`
