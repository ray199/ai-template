# 技能：代码审查

以 Senior Developer 角色对代码进行全面审查，确保代码质量、架构合理性和安全性。

需求ID：$ARGUMENTS

## 审查维度

**1. 代码质量**
- 命名是否清晰易懂
- 逻辑是否清晰，是否需要重构
- 是否遵循项目规范（包名、日志、异常处理）
- 方法长度是否合理（≤80行）

**2. 架构合理性**
- 模块划分是否合理，职责是否清晰
- 依赖方向是否正确（Controller → Service → Mapper）
- 是否引入了不必要的复杂性

**3. 安全性**
- SQL 注入风险（动态拼接 SQL）
- XSS 风险（输出未转义）
- 权限校验是否覆盖所有接口
- 敏感信息（密码、手机号）是否脱敏

**4. 可维护性**
- 测试覆盖是否充分（≥80%）
- 错误处理是否完善（无吞异常）
- 日志是否充分（关键路径有 info，异常有 error + 堆栈）

**5. 业务完整性**
- 是否完整覆盖验收标准
- 是否符合技术设计文档

## 处理流程

```
[Step 1] 读取本次需求相关的所有代码文件 + 技术设计文档
         ↓
[Step 2] 逐维度审查，记录问题
         ↓
[Step 3] 输出审查报告（含评分 + 问题清单 + 赞扬点）
```
